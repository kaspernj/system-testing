Make `clearAndSendKeys` clear inputs with a native Selenium `element.clear()` by default and add a selectable `clearStrategy` (`native` | `js` | `backspace-keys` | `delete-keys`) plus a configurable `keyDelay`. The deliberately slow per-character backspace/delete clearing is now opt-in only and never the default. Remove the silent `withFallback` sendKeys DOM value-setter fallback outright (pre-release, no compat); its behavior lives on as the first-class `clearStrategy: "js"` / `replaceValueWithJs` interact escape hatch. The former `replaceInputValue` collapses into `clearAndSendKeys` (its only difference was the removed default clear mechanism). Flaky clearing/typing is a controlled-input smell — the real fix is an uncontrolled input, documented in the README "Clearing inputs" section.
